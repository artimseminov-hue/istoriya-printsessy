# Это история одной принцессы

Интерактивная книга-подарок: видео-вступление, а после него — 3D-книга с главами, фотографиями, голосовыми записями, письмом и финальным видео.

Сайт открывается с `index.html` → вступление (`vstuplenie.html`) → после видео сайт сам переходит в книгу (`kniga.html`).
Перед началом — экран «поверни телефон горизонтально и включи звук» с кнопкой «Начать историю». Книга каждый раз начинается с первой главы.

## Посмотреть на своём компьютере
Дважды щёлкнуть «Открыть сайт.bat» (нужен Python). Пока смотришь, не закрывай окно сервера.
Если открыть `index.html` просто двойным щелчком, книга не загрузится: браузер не даёт сайту читать файлы с диска.

## Опубликовать на GitHub Pages
1. Создать репозиторий и загрузить в него **содержимое** этой папки (чтобы `index.html` лежал в корне).
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
3. Через минуту-две сайт появится по адресу `https://<имя>.github.io/<репозиторий>/`.

## Как менять содержимое
Все главы, тексты, подписи и пути к фото — в `content/content.js`.
Подробная инструкция — `CONTENT_GUIDE.md` (в ней пути начинаются с `site/`; здесь этой папки нет, всё лежит прямо в корне).
Финальное видео — `content/video/obrashchenie.mp4` (чтобы заменить, положите новый файл под тем же именем).
