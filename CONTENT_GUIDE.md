# Как наполнять книгу «История одной Светы»

Здесь описано, как добавлять фотографии, тексты, голосовые записи, письмо и видео.
**Код сайта трогать не нужно:** всё меняется в одном файле и в нескольких папках.

---

## Как устроена книга

```
Большая глава  (например, «Когда ты была совсем маленькой…»)
 ├─ Мини-глава 1  «Самое первое знакомство»   ← карточка-полароид на странице книги
 │    ├─ фото 1  (+ подпись, если нужна)
 │    ├─ фото 2
 │    ├─ … сколько угодно
 │    ├─ общий текст воспоминания (один на всю мини-главу)
 │    └─ голосовая запись (одна на всю мини-главу)
 ├─ Мини-глава 2  «Ты так быстро росла»
 └─ …
```

**Как это видит Света:**
1. На странице главы — карточки мини-глав: главное фото, название от руки на нижнем поле. Если в мини-главе несколько фото, за карточкой видна «стопка».
2. Первая мини-глава открывается сама. Следующая подсвечивается, над ней надпись «Нажми сюда», внизу «Посмотри, что дальше…».
3. Когда мини-глава открыта:
   - карточка тает, и из неё поднимаются все фото;
   - слева большое главное фото, под ним остальные;
   - справа текст воспоминания, под ним плеер, если есть голос;
   - голосовая запись включается сама, а фоновая музыка на это время становится тише.
4. Если фото несколько, главное фото само меняется по кругу примерно раз в 6 секунд. Нажатие на маленькое фото сразу делает его главным. Ещё можно листать стрелками ‹ 2 / 5 › внизу или свайпом влево/вправо на телефоне. Кнопка ❚❚ рядом со стрелками останавливает показ, ▶ — продолжает. Подпись к фото видна на полароиде.
5. «Продолжить» — фото возвращаются в карточку, книга подсвечивает следующую мини-главу.
6. Когда открыты все мини-главы, появляется «Перевернуть страницу», и начинается следующая большая глава.

Всю книгу играет фоновая музыка (`site/assets/audio/i-see-the-light.mp3`, тот же трек, что во вступлении) — по кругу, без перерывов между главами. Кнопка ♪ вверху справа выключает и включает её.

Уже открытые мини-главы можно пересматривать. В прошлые главы можно вернуться через «Оглавление» (вверху слева). Прогресс сохраняется в браузере.

## Где что лежит

Все пути — внутри папки `istoriya-svety/site/`.

| Что | Куда класть |
|---|---|
| **Файл со всеми главами, мини-главами и текстами** | `site/content/content.js` |
| Фото главы 1 | `site/content/foto/glava1/` |
| Фото главы 2 | `site/content/foto/glava2/` |
| Фото главы 3 | `site/content/foto/glava3/` |
| Фото главы 4 | `site/content/foto/glava4/` |
| Фото главы 5 | `site/content/foto/glava5/` |
| Голосовые записи (mp3, m4a, ogg) | `site/content/audio/` |
| Письмо подруги (.txt) и её фото | `site/content/pisma/` |
| Видеообращение (mp4) | `site/content/video/` |

Примеры (`content/foto/primer/…`, `primer_zvuk.mp3`, `primer_video.mp4`) нужны только для проверки. Их можно удалить, когда на них больше ничто не ссылается.

## Как называть файлы

- **Только латиница, цифры, дефис и подчёркивание.** Без пробелов и русских букв.
- Удобная схема: **`g<глава>-<мини-глава>-<номер фото>.jpg`**
  - `g1-1-01.jpg`, `g1-1-02.jpg` — глава 1, мини-глава 1, фото 1 и 2;
  - `g1-3-01.jpg` — глава 1, мини-глава 3 («День твоего крещения»), фото 1.
- Голос: `g1-1-mama.mp3`, `g1-4-babushka.mp3`.
- Регистр важен: `Foto.JPG` и `foto.jpg` — разные файлы. В `content.js` пишите имя буква в букву.
- Фото с телефона можно класть как есть: сайт сам уменьшит их. Но лучше, чтобы файл был не больше 2–3 МБ.

## Одна мини-глава в `content.js`

```js
{
  id: "g1-1", order: 1,
  title: "Самое первое знакомство",
  cover: "content/foto/glava1/g1-1-01.jpg",          // фото для карточки (необязательно: если пусто — первое из списка)
  photos: [
    { image: "content/foto/glava1/g1-1-01.jpg", caption: "Первый день дома" },
    { image: "content/foto/glava1/g1-1-02.jpg", caption: "" },
    { image: "content/foto/glava1/g1-1-03.jpg", caption: "С папой" }
  ],
  text: "Общий текст воспоминания — справа от фотографий.",
  author: "— мама",                                  // подпись под текстом (необязательно)
  audio: "content/audio/g1-1-mama.mp3",              // голос (необязательно)
  audioCaption: "Мама вспоминает"                    // подпись над плеером (необязательно)
},
```

| Поле | Что это | Обязательно? |
|---|---|---|
| `id` | уникальное имя мини-главы, например `"g1-1"` (не должно повторяться) | да |
| `order` | порядок открытия: 1, 2, 3… | да |
| `title` | название (пишется на карточке и в записке) | да |
| `cover` | главное фото для карточки | нет — возьмётся первое из `photos` |
| `photos` | список фото, **сколько угодно**: 1, 3, 7… | нет — будет заглушка |
| `caption` | подпись к конкретному фото (на полароиде) | нет |
| `text` | общий текст воспоминания | нет |
| `author` | подпись под текстом, например `"— мама"` | нет |
| `audio` | путь к голосовой записи | нет |
| `audioCaption` | подпись над плеером | нет |
| `hidden` | `true` — временно спрятать | нет |

**Пустые кавычки `""` означают «этого нет»** — такой блок не появится:
- нет текста и голоса — фото займут весь экран;
- есть голос, но нет текста — справа будет только плеер;
- нет подписи — нижнее поле полароида просто с цветами.

Новый абзац в тексте — `\n`:
```js
text: "Первый абзац.\nВторой абзац.",
```
Кавычки внутри текста — только «ёлочки».

## Как сделать по шагам

### 1. Добавить фото к мини-главе
1. Положите фото в папку главы, например `site/content/foto/glava1/g1-2-01.jpg`.
2. В `content.js` найдите нужную мини-главу и допишите строку в `photos`:
   ```js
   photos: [
     { image: "content/foto/glava1/g1-2-01.jpg", caption: "" },
     { image: "content/foto/glava1/g1-2-02.jpg", caption: "Подпись" }
   ],
   ```
3. **Между строками — запятые**, после последней строки запятую можно не ставить.

### 2. Выбрать главное фото для карточки
Укажите его в `cover`. Если `cover` не указан, карточкой станет первое фото из `photos`.

### 3. Изменить порядок фото внутри мини-главы
Переставьте строки в `photos`. Первое — главное при открытии.

### 4. Изменить порядок мини-глав
Поменяйте числа `order`. Удобно ставить 10, 20, 30 — тогда потом можно вставить 15.

### 5. Добавить голос
Положите файл в `site/content/audio/`, затем:
```js
audio: "content/audio/g1-1-mama.mp3",
audioCaption: "Мама вспоминает",
```
Запись **включается сама**, когда мини-глава открылась. Фоновая музыка на это время становится тише и потом возвращается. Если браузер не разрешает звук без нажатия, запись начнётся после первого касания экрана. Есть пауза, полоса перемотки и «послушать ещё раз».

### 6. Добавить новую мини-главу
Скопируйте целиком блок `{ … },` любой мини-главы, вставьте внутрь `stories: [ … ]` нужной главы и поменяйте `id`, `order`, название, фото и текст.

### 7. Временно спрятать мини-главу или одно фото
- Мини-главу: добавьте `hidden: true` в её блок.
- Одно фото: `{ image: "…", caption: "…", hidden: true },`

### 8. Видео в финале
1. Положите видео в `site/content/video/`, например `obrashchenie.mp4` (лучше mp4 H.264 — играет на всех телефонах).
2. В последней главе (`id: "final"`) поменяйте `video: "content/video/obrashchenie.mp4"`.
3. `poster` — картинка-заставка (необязательно).
4. `prelude` — на будущее, мультсцена перед видео: если указать путь, сначала проиграется она, потом видео.

### 9. Письмо подруги (глава 4)
1. Текст письма — в `site/content/pisma/pismo_podrugi.txt` (кодировка UTF-8). Абзацы разделяйте пустой строкой.
2. В главе 4:
   ```js
   {
     id: "g4-letter", order: 3, type: "letter",
     title: "Письмо от подруги",
     letter: "content/pisma/pismo_podrugi.txt",
     from: "Твоя Маша",                         // подпись в конце и на конверте
     fromPhoto: "content/pisma/podruga.jpg"     // необязательно
   },
   ```

## Готовые шаблоны (копируйте и меняйте)

Это примеры **структуры**, а не настоящие тексты.

**Мини-глава с одним фото и текстом**
```js
{
  id: "g1-2", order: 2,
  title: "Ты так быстро росла",
  photos: [
    { image: "content/foto/glava1/g1-2-01.jpg", caption: "" }
  ],
  text: "Здесь будет воспоминание.",
  audio: ""
},
```

**Мини-глава с несколькими фото, подписями и голосом**
```js
{
  id: "g1-3", order: 3,
  title: "День твоего крещения",
  cover: "content/foto/glava1/g1-3-02.jpg",
  photos: [
    { image: "content/foto/glava1/g1-3-01.jpg", caption: "В храме" },
    { image: "content/foto/glava1/g1-3-02.jpg", caption: "С крёстной" },
    { image: "content/foto/glava1/g1-3-03.jpg", caption: "" },
    { image: "content/foto/glava1/g1-3-04.jpg", caption: "Праздничный стол" }
  ],
  text: "Здесь будет общий рассказ о дне крещения.",
  author: "— мама",
  audio: "content/audio/g1-3-mama.mp3",
  audioCaption: "Мама рассказывает"
},
```

**Мини-глава только с голосом (без текста)**
```js
{
  id: "g1-4", order: 4,
  title: "Наши бабушки",
  photos: [
    { image: "content/foto/glava1/g1-4-01.jpg", caption: "Бабушка Аня" },
    { image: "content/foto/glava1/g1-4-02.jpg", caption: "Прабабушка" }
  ],
  text: "",
  audio: "content/audio/g1-4-babushka.mp3",
  audioCaption: "Голос бабушки"
},
```

**Только фото — без текста и голоса**
```js
{
  id: "g1-6", order: 6,
  title: "История с подъёмником",
  photos: [
    { image: "content/foto/glava1/g1-6-01.jpg", caption: "" },
    { image: "content/foto/glava1/g1-6-02.jpg", caption: "" }
  ]
},
```

## Как проверить результат

1. Запустите `istoriya-svety/Открыть вступление (видео).bat`. Откроется браузер.
2. Перейдите на `http://localhost:8779/kniga.html`.
3. Чтобы пройти с начала: «Оглавление» → «Начать книгу сначала».
4. После правки `content.js` просто обновите страницу (F5). Сервер не кэширует файлы, поэтому изменения видны сразу.

**Если файла нет или путь с ошибкой**, книга не сломается:
- вместо фото — заглушка «Здесь будет фотография» с именем недостающего файла;
- вместо голоса — «Запись пока не добавлена»;
- вместо письма — «Текст письма пока не добавлен»;
- вместо видео — «Видео пока не добавлено».

**Если книга не открылась после правки** — почти всегда виновата пропущенная запятая или кавычка. Внизу появится подсказка. Ещё помогает F12 → «Console»: там написано, в какой строке ошибка.

| Что не так | Как исправить |
|---|---|
| Видна заглушка с именем файла | Проверьте папку и имя файла буква в букву, включая `.jpg` / `.JPG` |
| Книга не открывается | Проверьте запятые между `{ … }` и строками `photos`, закрыты ли кавычки |
| Две мини-главы ведут себя странно | У них одинаковый `id` |
| Не тот порядок | Проверьте `order` и порядок строк в `photos` |

Старый формат (одно фото = одно воспоминание, поле `image` вместо `photos`) книга тоже понимает. Его можно не переделывать сразу.
